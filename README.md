# choice-support（えらぶ・じゃんけん）

タップで意思表示するための選択補助アプリです。「えらぶ」と「じゃんけん」の2つの機能を、タブで切り替えて使います。

タブレット（iPad など）での利用を想定した画面構成で、拡大縮小は無効、画面全体が1画面に収まります。

**公開URL: https://eduwithdai.github.io/choice-support/**

---

## 使い方

### 起動

上のURLをブラウザで開くだけです。インストールも設定も必要ありません。

画面上部にタブが2つあります。

| タブ | 用途 |
|---|---|
| 🗳️ えらぶ | 質問に対して選択肢をタップして答える |
| ✊ じゃんけん | 手を選ぶ／CPUと対戦する |

タブの右端にある 🔊 ボタンで、タップ音のON/OFFを切り替えられます。音を出せない場面では 🔇 にしておきます。

### 🖐️ タップの反応について

指1本できれいにタップできなくても操作できるようにしてあります。手が不自由な場合を想定した作りです。

- **触れた瞬間に反応します。** 押して離す動作を最後まで正確に行う必要はありません
- **複数の指や手のひらで触れても反応します。** 2本以上の指が同時に触れた場合は、最初に触れたものだけが1回だけ反応します
- **手のひらが2つのボタンにまたがっても、二重に反応しません。** 一度反応してから0.4秒間は次の接触を受け付けません
- **長く触れても、文字選択・拡大鏡・メニューは出ません**
- **複数の指が触れても画面が拡大縮小しません**

編集ボタンの長押しも、複数の指で押して大丈夫です。押し始めた指さえ触れていれば、他の指を離しても中断しません。多少手が動いても続きます。

## 🗳️ えらぶ

### 選ぶ

画面上部に質問文、その下に選択肢のボタンが並びます。**選択肢をタップすると次のことが同時に起こります。**

- 押したボタンが沈み込み、合図の絵文字（初期値は ⭕）が表示される
- 画面下部に「⭕「はい」を選びました！」というメッセージが出る
- **選んだ内容が画面いっぱいに拡大表示される**

拡大表示は、選んだ答えを相手にはっきり示すためのものです。

### 拡大表示を閉じる

**ダブルタップで閉じます。** 誤操作で閉じてしまわないよう、シングルタップでは閉じません。

### やり直す

選択後に現れる「リセット」ボタンで、選択前の状態に戻ります。

### プリセットを切り替える

画面下部のチップをタップすると、質問と選択肢のセットをワンタップで切り替えられます。

- **はい・いいえ** —「どちらですか？」
- **きけん・あんぜん** —「どっちかな？」

## ⚙️ 編集

### 🔒 編集画面は長押しで開きます

「⚙️ 編集」ボタンは、**約0.8秒押し続けたときだけ開きます。** 軽くタップしても何も起こりません。使用中に誤って編集画面に入ってしまうのを防ぐためです。

押している間はボタンが左から白く満ちていき、いっぱいになった時点で編集画面に切り替わります。途中で指を離す、または指を大きく動かすと中止され、ボタンは元に戻ります。

### 編集できること

右側のプレビューで仕上がりを確認しながら編集でき、「✅ 完成して使う」で play 画面に戻ります。

| 項目 | 内容 |
|---|---|
| プリセット | 既存セットの呼び出し |
| 質問文 | 画面上部に表示される文章 |
| 選択肢の数 | 2択 または 3択 |
| 選択肢 | 各ボタンのテキスト、および画像の差し替え |
| テーマカラー | 5種類の配色から選択 |
| 選択時の合図 | ⭕ 🌟 👍 🎉 ✅ 💡 🔥 ❤️ の8種類から選択 |

選択肢は**文字ボタンと画像ボタンのどちらでも使えます。** 画像を設定するとそのボタンは画像表示になり、画像を外すと文字ボタンに戻ります。文字が読めない場合でも絵で選べるようにするための仕組みです。

### ⚠️ 編集内容は保存されません

このアプリは編集内容を端末に保存しません。**ページを再読み込みしたりブラウザを閉じたりすると、初期状態に戻ります。**

同じ設定を繰り返し使いたい場合は、使うたびに編集し直すか、リポジトリの `index.html` 内の `PRESETS` にセットを追加してください（下記「カスタマイズ」参照）。

## ✊ じゃんけん

上部のボタンで2つのモードを切り替えます。

### 🙋 手を選ぶ

グー・チョキ・パーから1つをタップして、自分の手を示すモードです。勝敗の判定はありません。相手に手を伝えるための表示として使います。「リセット」で選び直せます。

### 🤖 CPUと対戦

コンピュータとじゃんけんで対戦します。流れは次のとおりです。

1. グー・チョキ・パーから手をタップする
2. 「じゃん・けん・ぽん！」のアニメーションが流れる
3. 自分とコンピュータの手が左右に並んで表示される
4. 結果が出る — **かった！🎉** / **まけた…😢** / **あいこ！🤝**
5. 「もう一度」で次の対戦へ

勝ち・負けにはそれぞれ効果音が鳴ります（🔊 がONのとき）。コンピュータの手は毎回ランダムに決まります。

## オフラインで使う

単一のHTMLファイルなので、ネットワークがなくても動きます。

```bash
git clone https://github.com/eduwithdai/choice-support.git
```

`index.html` をブラウザで開くだけです。ファイル1つをUSBメモリなどにコピーして持ち歩くこともできます。画像も音声もすべてファイル内に埋め込まれているため、他のファイルは必要ありません。

---

## カスタマイズ

すべての実装が `index.html` に収まっています。ビルド作業や依存パッケージはありません。

主な変更箇所は次のとおりです。

| やりたいこと | 変更する場所 |
|---|---|
| プリセットを追加する | `PRESETS` |
| テーマカラーを増やす | `PALETTES` |
| 合図の絵文字を変える | `EMOJIS` |
| 選択肢ボタンの色 | `CHOICE_COLORS` |
| じゃんけんの手の見た目 | `JAN` |

画像・音声は data URL としてファイル内に埋め込む方式です。差し替える場合も同じ形式にしてください。

変更を反映するには、`index.html` を編集して push します。GitHub Pages が自動で再ビルドし、1〜2分ほどで公開URLに反映されます。

```bash
git add -A && git commit -m "Update app" && git push
```
